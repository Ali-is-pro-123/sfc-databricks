# Step 43 — Menu intelligence dashboard

The SRS asks for menu-item performance, Profit Drivers, Volume Drivers, Hidden Opportunities, Low Performers, slow-moving items, ratings, margins and wastage. The login-required `/dashboard/menu/` page presents these for restaurants accessible to the user. It joins verified Step 34 item/location classes to Step 32 movement classes on the unique `(restaurant_code, item_code)` key. The historical window is 2026-04-02 inclusive through 2026-07-01 exclusive.

The four class cards count **item-location pairs**, not distinct menu items; the same item can be a different class at another restaurant. Step 32 slow-moving count is also an item-location count. Ratings use the number of observed ratings as weights; missing ratings are not zero. Aggregate direct margin is summed contribution divided by summed revenue, not an average of pair margins, and excludes overhead. Accounted wastage is accepted wasted portions divided by accepted sold plus wasted portions; it does not repair inventory gaps. Provisional classifications are counted and marked in the table. No class automatically triggers removal, promotion or repricing.

The item table is paginated and can be filtered by accessible location, local class, category, movement class and item name/code, then sorted by revenue, sold portions, direct margin, rating, wastage or name. Summary cards always cover **all accessible locations**, while filters narrow only the table; the page labels both scopes. Location choices and pagination links contain only validated, accessible location codes. Managers see granted locations; analysts/administrators see locations allowed by the existing access policy. Unauthenticated users are redirected to login.

The data service checks passed Step 34 and Step 32 reports, their common cutoff and 90-day window, source row counts, one-to-one pair coverage, unique scoped keys and full-scope financial/classification conservation. If source evidence is missing or inconsistent, the page shows an explicit unavailable state rather than partial success.

Run `uv run python dine_iq/manage.py test apps.restaurants.test_menu_dashboard` and `uv run python dine_iq/manage.py check`. The full verified snapshot has 4,320 item-location pairs: 202 Profit Drivers, 810 Volume Drivers, 1,229 Hidden Opportunities and 2,079 Low Performers. It also has 853 slow-moving pairs, 26,705 observed ratings and PKR 125,910,828.14 accepted revenue. These are synthetic analytical figures, not live data.
