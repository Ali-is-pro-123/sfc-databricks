# Visual assets

restaurant-table.png and dish-atlas.png are original generated representative food photographs. The atlas contains ten category photographs; it does not depict each recipe or claim evidence about a dish. Local UI labels disclose this. brand.svg is a native vector bowl/bar identity.

Geometric Book and Demi are URW Gothic. Editorial Roman is P052. FONT-LICENSE.txt retains the installed distribution copyright and font licensing terms. Assets and fonts load locally without an external CDN.
